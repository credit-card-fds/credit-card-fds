# agent/ 작업 규칙 (검토 보조 에이전트)

신용카드 FDS 과제 저장소 안의 확장 작업 폴더: RF 모델이 걸러 낸 리뷰 큐에 근거 요약과 검토 우선순위를 붙이는 검토 보조 에이전트.
설계와 진행 상황은 `PLAN.md`를 따른다.

## 진행 방식 (코드 작성 + 수업형 설명)
- `.py` 파일은 Claude가 작성한다.
- 작성한 뒤에는 **파일별로 모든 코드를** 수업하듯 자세히 설명한다.
  - 코드에는 한국어 주석을 충분히 단다.
  - "왜 이렇게 했는지", 문법 포인트, 확인하는 명령을 설명한다.
- 파일을 완성하면 실행해 확인하고 `PLAN.md` 체크리스트를 갱신한다.
- 구조·설계를 바꿀 때는 먼저 보여 주고 승인을 받은 뒤 진행한다.
- 유료 API 호출(에이전트 실행)은 사용자가 요청할 때만 한다.

## 설계 원칙
- **정답 라벨 `y_test`는 `evaluate.py`에서만 쓴다.** 도구와 에이전트에는 넘기지 않는다. (`y_train`은 "과거 사례"로 써도 된다.)
- **LLM 호출은 `agent.py`에만 둔다.** 나머지 파일은 API 키 없이 실행·테스트할 수 있어야 한다.
- 계산은 코드(도구)가, 해석과 요약은 LLM이 맡는다. 판정은 RF, 최종 결정은 사람.
- 경로와 상수는 `config.py` 한 곳에서만 정의한다.

## 규칙
- CSV는 크기와 상관없이 Git에 올리지 않는다.
- 주석은 한국어로, 과제 저장소와 같은 스타일로 쓴다.
- 이 폴더는 과제 저장소(`credit-card-fds`) 안의 하위 폴더다. 별도 git 저장소를 만들지 않으며, 커밋·push는 사용자가 요청할 때만 한다.
- 과제 쪽 파일(`experiments/`, `src/`)은 읽기만 하고 수정하지 않는다.

## 환경
- Python: `requirements.txt`를 설치한 환경
- 실행: `agent/` 폴더에서 `python main.py`
- 데이터: `../data/processed` (읽기만 함, 과제 쪽 `eda_and_split.ipynb` 실행으로 생성)
